Hexo + Github搭建博客

Intro
2018-02-08

写在前面emmmmm,本来这篇文章应该在去年6月份就写的，由于各种原因（好吧其实是懒~）荒废了，半年之后在一次CTF中，看到了许多优秀大学生关于比赛的wp后发现他们平时没事都在写博客，不断总结进步。于是，在一个伟大的日子里，我开始重新配置博客，但是出现了一大堆报错，浪费了半天的时间也没有解决，所以我把原来那个博客的配置文件删了，重新开始耗时两天建立了这个新的博客，用于总结和学习。环境准备安装Node.js这个没什么难的，一路next就能装好。
在命令行中输入验证是否配好,如果能显示版本号就代表环境配好了。
1 2 node -v npm -v

安装Git关于Git的下载和安装，参考这篇博客
安装完成后，打开Git Bash设置名称和邮箱
安装Hexo上述两步完成后，就可以开始安装Hexo，打开Git Bash
1 $ npm install -g hexo-cli

漫长的等待之后，Hexo就安装成功了。Github的配置

  • 首先注册,登陆Github
  • 然后右上角的加号，创建代码库（Create a new repository）

配置SSH本地生成公钥私钥
1 $ssh-keygen -t rsa -C "github的邮箱地址"

三次enter过后，会得到两个本地文件id_rsa、id_rsa.pub在C:\Users\用户名\.ssh用文本编辑器（不要用自带的记事本，切记）打开id_rsa.pub，复制全部内容，进入Github，Title的内容没要求，Key就是id_rsa.pub中的内容，然后Add SSH key初始化博客

  1. 选择一个目录，新建Blog文件夹（这个文件夹就是以后博客的配置文件夹）

  2. Git Bashcd到这个目录后，执行hexo init blog，漫长等待后提示成功
    1 INFO Start blogging with Hexo!

  3. 这个时候我们就可以看看初步的成果了，继续执行以下命令
    1 2 $ hexo generate $ hexo sever

在浏览器中输入localhost:4000,就可以看看博客初始的样子了。配置博客在blog目录下打开_config.yml文件，修改参数修改网站相关信息
1 2 3 4 5 6 title: 标题 subtitle: 副标题 description: 网站描述 author: 作者 language: zh-CN timezone: Asia/Shanghai

配置部署在最末尾的位置
1 2 3 4 deploy: type: git repo: https://github.com/yourname/yourname.github.io.git branch: master

发表第一篇文章

  • 新建一篇文章
    1 $ hexo new "测试文章"

  • 在提示的路径下找到该.md文件,使用Markdown语法编辑，关于Markdown语法可以看看这里，建议下载MarkdownPad简单便利。

  • 编辑保存之后就可以部署并发表了
    1 $ hexo d -g
