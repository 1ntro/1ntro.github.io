SQL注入

Intro
2018-02-22

SQL介绍SQLI，sql injection，我们称之为SQL注入。何为SQL，英文：StructuredQueryLanguage， 叫做结构化查询语言。常见的结构化数据库有 MySQL，MSSQL,Oracle 以及 Postgresql。Sql 语言就是我们在管理数据库时用到的一种。在我们的应用系统使用 sql 语句进行管理应用数 据库时，往往采用拼接的方式形成一条完整的数据库语言，而危险的是，在拼接 sql 语句的 时候，我们可以改变 sql 语句。从而让数据执行我们想要执行的语句，这就是我们常说的 sql 注入。注入的分类基于从服务器接收到的响应

  • 基于错误的SQL注入
  • 联合查询的类型
  • 堆查询注射
  • SQL盲注
    基于布尔SQL盲注
    基于时间的SQL盲注
    基于报错的SQL盲注

基于如何处理输入的SQL查询（数据类型）

  • 基于字符串
  • 数字或整数为基础的

基于程度和顺序的注入

  • 一阶注射
  • 二阶注射
    一阶注射是指输入的注射语句对WEB直接产生了影响，出现了结果；二阶注入类似储存型XSS，是指输入提交的语句，无法直接对WEB应用程序产生影响，通过其他的辅助间接的对WEB产生危害，称为二阶注入。

基于注入点的位置上的

  • 通过用户输入的表单域的注射。
  • 通过cookie注射。
  • 通过服务器变量注射。（基于头部信息的注射）

常用的几个函数介绍几个常用函数：

  1. version() –MySQL版本
  2. user() –数据库用户名
  3. database() –数据库名
  4. @@datadir –数据库路径
  5. @@version_compile_os –操作系统版本
  6. concat(str1,str2,…) –没有分隔符地连接字符串
  7. concat_ws(separator,str1,str2,…) –含有分隔符地连接字符串
  8. group_concat(str1,str2,…) –连接一个组的所有字符串，并以逗号分隔每一条数据
  9. 一般用于尝试的语句：
    • or 1=1–+
    • ‘or 1=1–+
    • “or 1=1–+
    • )or 1=1–+
    • ‘)or 1=1–+
    • “)or 1=1–+
    • “))or 1=1–+

注入攻击流程判断注入点找到注入点是最关键也是最基础的一个环节，找到一个需要后台处理提交给数据库的点，只要和数据库有交互的输入，都有可能触发SQL注入一般有三大类：GET、POST、Cookie三个参数触发形如http://localhost/test.php/?id=1这样的url或者有输入框的验证是否存在注入点，最常见的方法
1 2 3 http://localhost/test.php/?id=1' //返回错误说明有可能注入 http://localhost/test.php/?id=1' and 1=1 //返回正常 http://localhost/test.php/?id=1' and 1=2 //返回错误

判断注入类型数字型注入点假设网站的SQL查询语句如下：
1 2 $id=$_GET['id']; $sql="SELECT * FROM users WHERE id=$id";

测试方法：
1 2 http://localhost/test.php/?id=1 and 1=1 返回成功 http://localhost/test.php/?id=1 and 1=2 返回失败

字符型注入点和数字型类似的：
1 2 $id=$_GET['id']; $sql="SELECT * FROM users WHERE id='$id'";
1 2 http://localhost/test.php/?id=1' and '1'='1 返回成功 http://localhost/test.php/?id=1' and '1'='2 返回失败

搜索型注入点这里提一下SQL语句中LIKE操作符，其含有通配符%（多个字符）和_（单个字符）可以进行字符匹配查询数据，例如查询姓刘的人可以用LIKE 刘%其查询语句一般为：
1 2 $id=$_GET['id']; $sql="SELECT * FROM users WHERE id like'%$id%'";

测试方法：
1 2 http://localhost/test.php/?id=web%' and 1=1 and '%'='返回成功 http://localhost/test.php/?id=web%' and 1=2 and '%'='返回失败

因为and逻辑，只要一个条件不满足，就返回错误，所以其语句变成了SELECT * FROM users WHERE id like'%web%'and 1=1 and '%'='%'内联式SQL注入一般是登陆页面出现的，其SQL查询语句类似：SELECT * FROM admin WHER username='$name' AND password ='$passwd'如果过滤输入不严格的话我们只需要提交1'or '1'='就可以直接绕过登陆进入系统终止式SQL注入（最常用）终止式SQL注入是指我们在注入SQL代码时，将不需要被执行的代码注释掉，从而执行我们想要的查询，拿上面那个例子来说，如果我们在username提交1'or 1=1--+那么查询语句就变成了SELECT * FROM admin WHER username='1'or 1=1--+ AND password ='$passwd'我们注意到--+后面的代码都被注释掉从而并没有执行，这样同样达到了绕过的目的。终止字符串：--+，#，%23，%00，/*
