关于正则表达式

Intro
2018-03-19

写在前面关于正则表达式的问题，我每次都是遇到的时候翻翻文档，解决完问题后就再也没碰过，所以每次遇到要涉及正则表达式的问题又要重新看看正则表达式，于是今天特地认真总结一下。这篇文章主要是以Python为基础的。语法字符串是编程时涉及最多的一种数据结构，实际中我们对字符串的操作很广泛。
正则表达式就是一种用于匹配字符串的一种很高效的方法。正则表达式描述了一种字符串匹配的模式（pattern），可以用来检查一个字符串中是否包含字串，或者寻找匹配的子串。
例如：

  • runoo+b，可以匹配runoob、runooob、runooooob等，+代表前面的字符必须至少出现1次。（1次或多次）
  • runoo*b，可以匹配runob、runoob、runooooob等，*代表前面的字符可以不出现，也可以出现1次或多次。（0次、1次、多次）
  • colou?r，可以匹配color或者colour，?代表前面的字符最多可以出现1次。（0次、1次）

在正则表达式中，\d可以匹配一个数字，\w可以匹配一个字母或数字，.可以匹配任意字符。

  • '00\d'=>'001'
  • '\d\d'=>'01'
  • '\w\w\d\d'=>'ab34'
  • 'ab.'=>'abc'或'ab?'

以上都是匹配定长度的字符串，举个复杂的例子：\d{3}\s+\d{3,8}

  • \d{3}表示匹配3个数字
  • \s表示匹配一个空格（或者tab等空白符），\s+就表示至少有一个空格
  • \d{3,8}表示3到8个数字
    于是上述例子匹配的字符串就是形如023 123456等带区号的电话号码。

进阶在面对实际问题时，我们往往需要做到更精准的匹配,这里给出一些常用到的正则表达式：

  • [0-9a-zA-Z\_]+可以匹配至少一个数字、字母或者下划线组成的字符串
  • [0-9a-zA-Z]{5,15}可以匹配5到15个由数字或字母组成的字符串
  • (P|p)ython可以匹配Python或python
  • ^\d(\w+)\d$可以匹配由数字开头数字结尾中间是数字或字母的字符串

re模块介绍完正则表达式的基础，下面说说它在Python中的应用。
Python提供re模块，包含所有正则表达式的功能。由于Python字符串本身用\转义，所以推荐使用Python的r前缀。
s = 'ABC\\-123'=>对应匹配的字符串ABC-123
s = r'ABC\-123'=>对应的就是ADBD-123compile(pattern)将正则表达式编译成一个对象。把那些经常使用到的正则表达式编译成正则表达式对象，可以提高效率。
1 2 3 4 >>> import re >>> telephone = re.compile(r'^(\d{3})-(\d{3,8})$') >>> telephone.match('023-121212').groups() ('023', '121212')

search(pattern,string)在字符串中寻找模式。找到则返回一个Match对象，否则返回None。
1 2 >>> re.search('abd','aaabd') <_sre.SRE_Match object; span=(2, 5), match='abd'>

match(pattern,string)match()方法判断是否匹配，匹配成功返回一个Match对象，否则返回None。
1 2 3 >>> import re >>> re.match(r'^(\d{3})-(\d{3,8})$','023-12321') <_sre.SRE_Match object; span=(0, 9), match='023-12321'>

findall(pattern,string)findall()方法可以获取字符串中所有匹配的字符串，并以列表形式返回匹配项。
1 2 >>> re.findall('a','abdsarat') ['a', 'a']

group()group（）方法主要用在Match对象提取子串。
1 2 3 4 5 6 7 8 9 >>> m = re.match(r'^(\d{3})-(\d{3,8})$', '010-12345') >>> m <_sre.SRE_Match object; span=(0, 9), match='010-12345'> >>> m.group(0) '010-12345' >>> m.group(1) '010' >>> m.group(2) '12345'

最后正则表达式在实际中运用很广泛，尤其是Python爬虫。还有就是写脚本的时候，有时候会遇到捕捉动态的网页数据时，一个好的正则表达式就会起到很大的作用。
