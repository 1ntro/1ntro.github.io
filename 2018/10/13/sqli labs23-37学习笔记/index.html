Less-23 过滤注释符首先随便给个1’，然后再1‘ or ‘1’=’1，根据两次回显信息可知，对id的处理为**‘$id’**，然后尝试一般的注入流程，得到报错，从源码中才得知

所以这里我们的payload中就不能包含注释符，那么就尝试将右边的单引号给去掉
1 2 ?id=-1' union select 1,2,3 or '1'='1 //没有报错 ?id=-1' union select 1,2,3,4 or '1'='1 //得到报错，得知列名有三行，并知道了有回显的那一行

然后就很简单了
Less-24 二次注入（储存型注入）第一次解除这种类型的题，网上搜了下思路：

  1. 通过构造数据提交到服务端进行处理
  2. 服务端将数据存储到数据库
  3. 再次向服务端提交请求，导致第一次构造的SQL语句得到执行
  4. 服务端返回结果
    这里我们首先注册一个**admin’#**的账号，密码为123，然后登录该账号修改密码，此时修改的就是admin的密码，源码：
    $sql = "UPDATE users SET PASSWORD='$pass' where username='$username' and password='$curr_pass' ";
    相当于我们执行了$sql = "UPDATE users SET PASSWORD='newpassword' where username='admin'#' and password='123' ";这样就修改admin的密码为newpassword

Less-25 过滤or、and本关考察对or和and的过滤，一般几个思路：

  1. 大小写变形Or OR oR
  2. 编码，hex，urlencode
  3. 添加注释/*or*/
  4. and = &&、or = ||
  5. 重复 oorr、aandnd

  1. 在前面加上%df，urlencode(\‘) = %5c%27，在前面加上%df就成了%df%5c%27，而%df%5c就是一个汉字，所以逃过了\
  2. 将\去掉，在前加上一个或奇数个\,后面的%5c就会被前面的注释掉
